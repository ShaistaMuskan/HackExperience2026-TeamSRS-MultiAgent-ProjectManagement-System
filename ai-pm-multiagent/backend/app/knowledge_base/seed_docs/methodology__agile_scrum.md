# Methodology Guide: Agile Scrum

Best suited for projects with evolving requirements, iterative delivery, a need for
fast feedback loops, and startup/product environments. Organizes work into sprints
(1-4 weeks) with a backlog, sprint planning, daily standups, sprint review, and
retrospective. Roles: Product Owner, Scrum Master, Development Team.

Signals in a project brief that suggest Scrum: "sprint", "iterative", "backlog",
"MVP", "fast-moving", "startup", "evolving requirements", frequent stakeholder demos.

Recommended artifacts: Product Backlog, Sprint Backlog, Burndown Chart, Increment.
