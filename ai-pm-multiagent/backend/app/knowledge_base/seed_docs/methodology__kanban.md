# Methodology Guide: Kanban

Best suited for continuous flow work such as support, maintenance, and operations
teams where work arrives unpredictably and priorities shift often. Uses a visual
board with WIP (work-in-progress) limits rather than fixed-length iterations.

Signals: "continuous", "support", "maintenance", "helpdesk", "ongoing operations",
"ticket-based", "flow efficiency".

Recommended artifacts: Kanban board (To Do / In Progress / Done), cumulative flow
diagram, cycle time / lead time metrics.
