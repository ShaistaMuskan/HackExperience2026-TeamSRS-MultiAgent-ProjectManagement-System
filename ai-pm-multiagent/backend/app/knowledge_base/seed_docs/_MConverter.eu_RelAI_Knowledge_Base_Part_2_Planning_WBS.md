## Purpose

This section teaches Rel.AI how to convert project requirements into an executable project plan rather than merely summarizing requirements.

## 1. Planning Workflow {#planning-workflow}

1\. Analyse project objectives.\
2. Identify deliverables.\
3. Break deliverables into work packages.\
4. Create tasks.\
5. Estimate effort.\
6. Assign owners.\
7. Detect dependencies.\
8. Identify milestones.\
9. Calculate critical path.\
10. Validate schedule.

## 2. Work Breakdown Structure (WBS) {#work-breakdown-structure-wbs}

Rules:\
• Break work by deliverable, not department.\
• Continue decomposition until work can be estimated and assigned.\
• Every task should have one owner.\
• Avoid overlapping work.\
• Every work package should produce a measurable outcome.

## 3. Task Decomposition Heuristics {#task-decomposition-heuristics}

Large tasks should be decomposed if:\
• Estimated duration exceeds one sprint.\
• Multiple owners are required.\
• Multiple deliverables exist.\
• Acceptance criteria cannot be clearly defined.

## 4. Estimation {#estimation}

Estimate using complexity, technical uncertainty, external dependencies, historical effort, team capacity and risk.\
Confidence:\
High -- similar historical work.\
Medium -- partial uncertainty.\
Low -- novel technology or incomplete requirements.

## 5. Dependency Detection {#dependency-detection}

Infer dependencies by asking:\
• Must Task A finish before Task B?\
• Does another team provide an input?\
• Is approval required?\
• Is external delivery required?\
Types:\
Finish-to-Start\
Start-to-Start\
Finish-to-Finish\
External\
Resource

## 6. Critical Path Rules {#critical-path-rules}

A task is on the critical path if delaying it delays project completion.\
Critical-path tasks receive highest monitoring priority.\
Changes affecting the critical path automatically increase project risk.

## 7. Planning Validation Checklist {#planning-validation-checklist}

Before finalizing:\
✓ Every deliverable mapped to tasks.\
✓ Every task has owner.\
✓ Every milestone has date.\
✓ Dependencies validated.\
✓ No orphan tasks.\
✓ Risks identified.\
✓ Resource conflicts checked.

## 8. Rel.AI Reasoning Playbook {#rel.ai-reasoning-playbook}

When planning:\
1. Retrieve historical examples.\
2. Select methodology.\
3. Generate WBS.\
4. Estimate effort.\
5. Infer dependencies.\
6. Calculate critical path.\
7. Flag planning gaps.\
8. Produce confidence score.
