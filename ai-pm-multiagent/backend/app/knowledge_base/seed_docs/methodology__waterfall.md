# Methodology Guide: Waterfall

Best suited for projects with fixed, well-understood scope, regulatory or
contractual constraints, and low tolerance for mid-project scope changes.
Phases execute sequentially: Requirements -> Design -> Implementation ->
Verification -> Maintenance, each with a formal sign-off gate.

Signals: "fixed scope", "regulatory", "compliance", "contract", "sequential",
"government", "audited", "formal sign-off".

Recommended artifacts: Requirements Specification, Design Document, Test Plan,
Phase Gate Sign-off Sheet.
